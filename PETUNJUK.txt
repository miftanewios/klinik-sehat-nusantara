2. Buka index.html melalui Live Server (disarankan), bukan dengan mengubah nama folder/path file.
3. Login prototipe admin:
   Username: admin
   Password: klinik2026
4. Data pendaftaran tersimpan di localStorage browser yang sama. Admin harus dibuka pada browser/perangkat yang sama.
5. Ini masih prototipe front-end. Kredensial admin dan data tidak aman untuk penggunaan klinik sungguhan karena belum memakai server/database.

Perbaikan utama:
- Memperbaiki path CSS admin agar sama dengan halaman lain.
- Validasi dokter sekarang memastikan dokter benar-benar berasal dari poli yang dipilih.
- Validasi nama mendukung huruf beraksen, gelar/tanda titik, apostrof, dan tanda hubung.
- Penyimpanan lokal lebih tahan terhadap data rusak dan kegagalan penyimpanan.
- ID pendaftaran dibuat lebih unik.
- Panel admin menghitung status dengan aman dan mengurutkan pendaftaran terbaru.
- Perubahan data dari tab browser lain dapat memperbarui panel admin.
- Aksi terima/tolak hanya berjalan saat sesi admin aktif dan status masih Menunggu.

FITUR CUSTOMER SERVICE (BARU):

- Halaman kontak.html: info kontak + form yang membuka WhatsApp dengan pesan terisi.
